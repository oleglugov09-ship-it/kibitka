# Ночь 24.11.2026: земля базового мира на Terrain3D

Решения, принятые по ходу (по одной строке):

- Terrain3D 1.1.0 кладём в `project/addons/terrain_3d`; из библиотек оставлены Linux и веб без потоков — остальные платформы берутся из выпуска Terrain3D при надобности.
- Шаг сетки 4 м (как у прежней самой подробной земли), регион 256 точек = 1024 м.
- Запекаются регионы в 2 км от любой дороги; дальше — ровный фон Terrain3D.
- Terrain3D нельзя двигать, а игра сдвигает начало координат к кибитке. Решение: свой шейдер с `world_shift` (tools/terrain-shader.py), начало координат сцены теперь кратно 1024 м по x и z.
- Цвет места (трава разных краёв, скала, ил, обочина) — карта цвета Terrain3D; её альфа — «насколько это трава», по ней красит сезон.
- Вода — готовые сетки на регион (`project/terrain/water`), запекаются вместе с землёй.
- В браузерной сборке собственная загрузка папки Terrain3D (`set_data_directory`) падает с делением на ноль; регионы грузим по одному через `ResourceLoader` + `add_region` — так работает и там, и на столе.
- Запекание запускается на первом кадре, а не в `ready`: внутри `ready` создание второго узла Terrain3D роняло Godot.
